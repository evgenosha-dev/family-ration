Как бесплатно опубликовать сайт на GitHub Pages
  1. Зарегистрируйтесь на github.com и создайте репозиторий (зелёная кнопка New), имя любое, например family-ration.
  2. Загрузите файлы проекта: на странице репозитория нажмите Add file → Upload files и перетащите все файлы и папки family-ration (index.html, css, js, README.md, .nojekyll, .github).
  3. Нажмите Commit changes.
  4. Откройте Settings → Pages (пункт в меню слева). В разделе Branch выберите ветку main, папку / (root) и нажмите Save.
  5. Через 1–2 минуты сайт будет доступен по адресу https://ваш-логин.github.io/family-ration/.

В папке проекта уже лежит готовый GitHub Action (папка .github/workflows) — с ним публикация происходит автоматически при каждом «пуше».
