# 🥗 Семейный рацион

Статический сайт: **сбалансированное меню на троих** (девушка 26, парень 26, сын 2 года) с расчётом калорий и БЖУ, фильтрами по стилю питания, аллергенам и кухням, а также **сравнением цен и отзывов продуктовых магазинов** с выбором самого выгодного места для заказа продуктов.

Публикуется бесплатно на GitHub Pages — без сервера и сборки, чистые HTML/CSS/JS.

## Возможности

- Расчёт норм питания каждого члена семьи (формула Миффлина — Сан Жеора для взрослых, весовой метод для ребёнка), параметры редактируются
- Генерация меню на день: завтрак, обед, ужин, 2 перекуса с точной калибровкой под норму калорий
- Перегенерация отдельного блюда кнопкой ⟳
- Фильтры: вегетарианство, веганство, «без мяса», детские блюда, 5 кухонь, исключение аллергенов (молочное, глютен, яйца, орехи, рыба, морепродукты)
- Сравнение 6 магазинов: Пятёрочка, Магнит, ВкусВилл, Лента, Ozon, Яндекс Лавка
- «Оптимальная корзина»: каждый продукт в самом дешёвом магазине + экономия
- Лучший магазин по цене и по отзывам
- Недельный бюджет с предупреждением о перерасходе
- Копирование списка покупок и печать

## Как редактировать цены и продукты

Все данные — в файле **`js/data.js`**:

- `STORES` — магазины, их базовый рейтинг (отзывы)
- `PRODUCTS` — продукты: `base` (цена за кг/шт), `p/f/c/kcal` (БЖУ на 100 г), `notAt` (где нет в наличии), `mult` (своя цена в конкретном магазине)
- `RECIPES` — рецепты: `ing` = `{ id_продукта: граммы }`, питательность считается автоматически

## Запуск локально

Просто откройте **`index.html`** двойным щелчком. Или поднимите простой сервер:

```
python -m http.server 8000
```

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub (например, `family-ration`).
2. Загрузите файлы проекта в ветку `main`.
3. **Settings → Pages → Build and deployment → Source: Deploy from a branch** → ветка `main`, папка `/ (root)`.
4. Готово: `https://ваш-логин.github.io/family-ration/`.

Либо оставьте файл `.github/workflows/pages.yml` — деплой выполнится автоматически при каждом «пуше».

## Варианты сайта

В папке `variants/` лежат альтернативные варианты реализации:

- `v2-single-file/` — вся «основная» версия в одном HTML-файле (удобно открывать и пересылать)
- `v3-weekly/` — вариант на целую неделю (меню 7 дней + недельная корзина)
- `v4-constructor/` — ручной конструктор: выбираешь блюда сам, в реальном времени видишь БЖУ и стоимость

Чтобы опубликовать другой вариант, скопируйте нужный `index.html` в корень репозитория.

## Структура основного приложения

```
index.html          — разметка страницы
css/style.css       — стили (+ адаптив и печать)
js/data.js          — магазины, продукты, рецепты (вся «база»)
js/nutrition.js     — расчёт норм питания и БЖУ
js/menu.js          — фильтры и генератор меню
js/shopping.js      — список покупок, цены, сравнение магазинов
js/app.js           — интерфейс и логика страницы
```
