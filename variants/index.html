🥗 Семейный рацион — варианты сайта

Четыре варианта одного приложения — сбалансированное меню для семьи (девушка 26, парень 26, сын 2 года) и сравнение цен в продуктовых магазинах. Выберите тот, что нравится, и опубликуйте на GitHub Pages.

Основной

Меню на день + магазины

Генератор меню по фильтрам с точной нормой калорий, «оптимальной корзиной», экономией и недельным бюджетом.

Открыть → Быстрый

Всё в одном файле

Тот же основной вариант, но в одном HTML-файле. Открывается двойным щелчком, легко переслать одним файлом.

Открыть → Неделя целиком

Планировщик на 7 дней

Меню сразу на неделю с равномерным распределением блюд, недельной корзиной и сравнением итоговой суммы по магазинам.

Открыть → Ручной

Конструктор меню

Соберите день своими руками: выбираете блюда в каждый приём пищи, а БЖУ, калории и цена корзины считаются вживую.

Открыть →
Все варианты используют одну базу продуктов и рецептов (js/data.js): цены, рейтинги магазинов и состав редактируются в одном месте. Инструкция по публикации на GitHub Pages — в README проекта.
